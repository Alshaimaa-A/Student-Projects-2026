# Student Projects Submission

Welcome to the Student Projects Repository!

Each student must submit their project according to the following instructions.

## Submission Instructions

1. Create a folder using your Student Name and ID.
2. Upload all required project files inside your folder.
3. Include a PDF report if required.
4. Make sure your files are complete before submission.

## Important Rules

- Each student must use their own folder.
- Do not modify or delete other students' files.
- Use clear file names.
- Do not upload unnecessary files.

Good luck!
